# IBM Plex Sans

Original, unmodified IBM Plex Sans font files from [IBM/plex](https://github.com/IBM/plex/tree/763c36ef9117782905ae010056dfbe8fd2653a25). Licensed under the SIL Open Font License 1.1; see LICENSE.txt.

The four weights match the existing design tokens. Local assets remove the Google Fonts build-time network dependency and the Windows Turbopack Google-font resolver failure.
